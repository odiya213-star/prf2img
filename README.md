# PDF 이미지 추출기

PDF의 각 페이지를 PNG로 변환해 하나의 ZIP 파일로 내려받는 정적 웹앱입니다. PDF 데이터와 결과물은 브라우저 메모리에서만 처리되며, 서버로 전송하거나 저장하지 않습니다.

## 실행

브라우저의 모듈 보안 정책 때문에 파일을 더블클릭하기보다, 이 폴더에서 간단한 로컬 웹 서버로 여는 것을 권장합니다.

```powershell
python -m http.server 8000
```

그런 다음 `http://localhost:8000`을 엽니다. 인터넷 연결 없이 사용할 수 있습니다.

## 동작 방식

- `vendor/`에 포함된 PDF.js가 선택한 PDF를 브라우저에서 읽습니다.
- 각 PDF는 페이지별 PNG로 렌더링됩니다.
- 한 번에 여러 PDF를 고르면 최대 2개 파일을 동시에 처리합니다. 각 파일의 이미지는 ZIP 내부에서 해당 PDF 이름의 폴더에 담깁니다.
- ZIP 파일은 브라우저의 `Blob`으로 생성되어 바로 다운로드됩니다.
